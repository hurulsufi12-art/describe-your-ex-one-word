## The word

**Unsubscribed** — the ex, filed away like a spam newsletter: unsubscribed from my life.

## How it works

`main.py` (Python 3 stdlib only, no network, no dependencies) validates
the word against the gate — UTF-8 text, 1–111 characters, exactly one
word, letters only — and then writes it, with no trailing newline, to
`/output/entry.txt`.

## Run

```sh
python3 -P -s main.py
cat /output/entry.txt
```
